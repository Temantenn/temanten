## Technical Implementation

All pixel art effects are achieved through:
- CSS `box-shadow` for pixel patterns
- CSS `linear-gradient` and `repeating-linear-gradient` for textures
- Inline SVG for scalable vector graphics
- CSS animations for interactive effects
- No external image files required
